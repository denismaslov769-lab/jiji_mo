# Моды сборки Godjo

* `cars.csv` — автопак: `id;имя_в_GTA;исходный_файл;название;цена;класс`. Из него:
  * CI собирает `godjo-cars.zip` (`modloader/godjo_cars/<имя_в_GTA>.dff/.txd`);
  * `tools/gen-carlist.py` генерирует `gamemode/modules/carlist.inc` (каталог автосалона, цена в игре = цена/20).
* Исходные модели лежат в `vendor/cars/godjo-cars.7z.b64.*` (7z, разрезанный base64 — репозиторий заполняется текстом).
* Текстуры экранов загрузки генерирует `tools/ci/make-textures.py`.

Заменять можно только ID, которые не используются модом (работы, автошкола, штатные машины салона) — см. список в `cars.csv`.
Как добавить машину: положить dff/txd в архив, добавить строку в `cars.csv`, выполнить `python3 tools/gen-carlist.py`.
