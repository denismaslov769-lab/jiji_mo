# Генераторы маршрутов

Точки для экзамена, автобусов, такси, работ и ботов снимаются с путевых узлов GTA SA
(`NODES0..63.DAT` из пакета FCNPC — те же узлы, по которым ездит трафик игры), поэтому
лежат на дорогах/тротуарах, а не на крышах.

1. `python3 nodes.py` — разбирает `NODES*.DAT` в `nodes.json` (путь к узлам — переменная `D`).
2. `python3 gen_routes.py` — пишет `gamemode/modules/gen_routes.inc` и координаты квестовых точек.
3. `python3 gen_bots.py` — пишет `gamemode/filterscripts/bots_paths.inc` (маршруты ботов).

Высота точек = высота узла + 1.0 (уровень ног персонажа).
