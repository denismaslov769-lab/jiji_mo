# Генератор интерьеров

`python3 tools/interiors/gen_interiors.py` строит больницу All Saints из стен/пола/мебели и пишет
`gamemode/modules/gen_interiors.inc` и `database/migrations/005.sql` (точки входа, кабинетов, палаты).

Перед записью работает валидатор: мебель не пересекается и не торчит из стен, все точки стоят на свободном
полу, от входа пешком (радиус игрока 0.3 м) достижимы все кабинеты и персонал. Если что-то не так — генератор
падает с описанием ошибки и ничего не пишет.

Размеры моделей — `model_aabb.json` (AABB из Model-Sizes-Plus). Только модели SA-MP 0.3.7.
