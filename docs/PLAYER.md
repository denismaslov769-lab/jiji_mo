# Как начать играть на Godjo Role Play

1. Есть GTA San Andreas + **SA-MP 0.3.7-R1/R3** — укажите папку. **Нет игры** — нажмите в лаунчере **«Скачать игру»**: он скачает готовую сборку целиком (игра + SA-MP + все моды Godjo).
2. Запустите **`GodjoSetup.exe`** → «Установить» (или распакуйте `GodjoRP-Launcher.zip` вручную).
3. Укажите ник в формате **Имя_Фамилия** (латиницей, например `Ivan_Petrov`) и папку с игрой.
4. Нажмите **«Играть»** — откроется экран загрузки: лаунчер сам поставит сборку Godjo (CEF, интерфейс, Modloader, 77 машин, экраны загрузки) и подключит к серверу.
5. Моды сборки можно отключить во вкладке **«Сборка»**.

Если GTA установлена в `Program Files`, запускайте лаунчер от имени администратора.
Для работы лаунчера нужен Microsoft Edge WebView2 (в Windows 10/11 уже есть).

## Управление
* **ALT** — взаимодействие (NPC, двери, кассы, банкоматы)
* **I** или **Y** — инвентарь, **P** — телефон, **N** — двигатель в машине
* **Esc** — закрыть окно интерфейса
* `/anims` — анимации, `/belt` — ремень, `/rules` — правила
* `/help` — все команды, `/gps` — навигатор, `/quest` — задания
