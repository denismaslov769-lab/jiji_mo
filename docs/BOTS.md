# NPC-боты (FCNPC)

Боты — отдельный filterscript `godjo_bots` (`gamemode/filterscripts/godjo_bots.pwn`), работают через плагин
[FCNPC 2.0.11](https://github.com/ziggi/FCNPC) (только SA-MP 0.3.7 **R2/R3**).

* ~20 пешеходов (прогулка, пробежка, дворники, разговор по телефону) и 6 водителей (автобус, 2 такси, легковые) по маршрутам из `bots_paths.inc`.
* RP-ники и ID как у игроков, уровень и пинг для TAB/`/online` передаются в мод (`GM_BotRegister`).
* Болтают между собой (15 сценок), отвечают на приветствия игроков рядом, убегают при стрельбе, периодически «выходят» и «заходят».
* Сервер: `plugins cef.dll FCNPC.dll`, `filterscripts godjo_bots`, `maxnpc 30` (уже в `server.cfg`).
  Если плагин не загружен — filterscript не стартует, мод работает без ботов.
* Маршруты генерируются скриптами `tools/routes/` (см. README там).
* Админ-команда `/bots` (3 ур.) — список ботов.
