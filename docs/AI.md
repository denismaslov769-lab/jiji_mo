# Жители-агенты (godjo_ai) — «симуляция игроков»

`gamemode/filterscripts/godjo_ai.pwn` + модули `gamemode/filterscripts/ai/*`. Заменяет `godjo_bots`
(старый скрипт остаётся в репозитории: `filterscripts godjo_bots` в `server.cfg` вернёт его).
Нужен плагин FCNPC 2.0.11 (SA-MP 0.3.7 R2/R3), `maxnpc 30`.

## Что умеет житель
* **Личность**: 5 черт (общительность, трудолюбие, любопытство, вспыльчивость, вежливость), пол, скин, уровень, пинг.
* **Потребности**: сытость, бодрость, общение, досуг — убывают со временем, восстанавливаются действиями.
* **Расписание**: часы бодрствования, рабочая смена. Онлайн следует суточной кривой (ночью мало, вечером пик);
  жители заходят по одному, сессия 25–125 мин, уходят «домой» пешком и только там выходят.
* **Работа**: дворник (Першинг-сквер), офис (мэрия/банк — заходит внутрь), продавец (ларёк/24/7), курьер,
  водитель/таксист/водитель автобуса (смены разнесены по суткам, машина создаётся на смену).
* **Мозг**: Utility AI — оценка целей (еда, работа, общение, прогулка, отдых, домой) с инерцией
  (обязательство + гистерезис: не дёргается между целями). Цель раскрывается в план задач (HTN-lite):
  `идти -> зайти внутрь / анимация / подметать / ждать друзей / выйти`.
* **Навигация**: пешеходный граф Лос-Сантоса (≈6000 узлов) из путевых узлов GTA SA + A* с кучей.
  Застрял — пропускает узел (если никто не видит — переставляется).
* **Память**: знакомства, нападения, оскорбления, благодарности, вопросы о дороге; важность гаснет на 1 в сутки.
* **Отношения**: симпатия и знакомство с каждым игроком/жителем (`ai_relations`).
  Знакомых приветствует по имени, обидчика помнит 3 дня и не подпускает.
* **Разговор с игроком** (обычный чат рядом, или по имени до 15 м): намерение (привет, как дела, имя, работа,
  «где …», «что делаешь», деньги, «ты бот?», оскорбление, спасибо, пока) -> желание отвечать
  (характер + отношение + занятость) -> знания (24 места города: направление и расстояние) -> стиль
  (вежливый / простой / грубоватый) -> анти-повтор -> задержка «печати». Отвечая, останавливается и поворачивается.
* **Друг с другом**: на «тусовочных» местах заводят разговоры (15 сценок), знакомятся.
* **Реакции**: при уроне — крик и бегство, обидчик получает розыск (как раньше), при смерти житель «выходит» на 20–50 мин.
* **LOD**: рядом с игроком (60 м) думает каждые ~2 с и здоровается; вдали — раз в ~8 с. Колесо времени:
  за такт (250 мс) думают не больше 4 агентов.

## Данные
* `ai_agents` — население (по умолчанию 40, генерируется при первом запуске), `ai_memory`, `ai_relations`,
  `ai_sessions` (журнал входов/выходов). Аккаунт жителя в `accounts` помечен `is_agent=1` — войти под этим ником нельзя.
* Миграция `006.sql`; filterscript создаёт таблицы и сам.

## Команды (админ 3+)
* `/aibots` — статус; `/aibots on|off|max N|list`.
* `/aibot [playerid | id жителя | часть имени] info|goto|task <eat|work|social|wander|home|idle>|memory|rel|stop|start|login|debug`.

## Генераторы
* `tools/ai/gen_navgraph.py` — граф из `nodes.json` (см. `tools/routes/nodes.py`, узлы из пакета FCNPC).
