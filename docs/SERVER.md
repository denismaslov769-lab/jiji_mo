# Запуск сервера Godjo Role Play (Windows)

1. Скачайте `GodjoRP-Server.zip` из последнего релиза и распакуйте, например, в `C:\GodjoRP`.
2. Откройте `server.cfg` и **смените `rcon_password`**.
3. Запустите `open-ports.bat` от имени администратора (откроет порты 7777/UDP и 7779/TCP+UDP).
   На роутере/VPS также пробросьте/откройте эти порты.
4. Запустите `start.bat`. При первом старте создастся база `scriptfiles\godjo.db` со всеми данными.
5. Зайдите в игру через лаунчер, войдите в RCON (`/rcon login пароль`) и выдайте себе админку: `/makeadmin [ваш id] 5`.

## Адрес сервера в лаунчере
Лаунчер берёт IP из `manifest.json` релиза. Задайте его один раз:
*Settings → Secrets and variables → Actions → Variables* → `GODJO_SERVER_IP` (и при необходимости `GODJO_SERVER_PORT`),
затем перезапустите workflow *build*. Также IP можно ввести вручную в настройках лаунчера (⚙) или в `launcher.json`.

## Координаты точек
Все точки (двери, NPC, работы, банкоматы, бутылки…) хранятся в таблице `locations`.
Если что-то стоит неудобно — встаньте в нужное место и введите `/setloc код` (админ 4+), затем `/gmx`.
Список кодов: `/locs`, телепорт к точке: `/tp код`.

## Обновление мода
* Новые таблицы/поля — добавляйте файлы `database/migrations/001.sql`, `002.sql`… Они выполнятся один раз автоматически.
* `seed.sql` выполняется только на пустой базе.
* Резервная копия — просто скопируйте `scriptfiles\godjo.db` (при остановленном сервере).

## Сборка вручную (без GitHub)
`tools\build-gamemode.bat C:\путь\к\pawncc.exe` — соберёт `build\server\gamemodes\godjo.amx`.
Нужен компилятор Pawn 3.10.x (pawn-lang/compiler). CEF-плагин `cef.dll` собирается только в CI.
